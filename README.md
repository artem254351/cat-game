# Игра для котика: Красная точка

Интерактивная игра для котиков и их друзей, где нужно ловить красную точку! Игра оптимизирована для мобильных устройств и отлично работает на телефонах.

## 🎮 Особенности игры

- **Адаптивный дизайн** - игра отлично работает на телефонах, планшетах и компьютерах
- **Интуитивное управление** - просто нажимай на красную точку пальцем
- **Система очков** - каждая пойманная точка приносит +1 очко
- **Таймер** - игра длится 60 секунд
- **Пауза и сброс** - возможность поставить игру на паузу или начать заново
- **Анимации** - плавные анимации и визуальные эффекты
- **Виброотклик** - тактильная обратная связь на мобильных устройствах

## 📱 Как играть

1. Откройте игру на телефоне или компьютере
2. Нажмите кнопку "Начать игру"
3. Нажимайте на красную точку, которая появляется в случайных местах
4. Старайтесь поймать как можно больше точек за 60 секунд
5. Используйте кнопку "Пауза" для временной остановки игры
6. Нажмите "Сброс" чтобы начать новую игру
